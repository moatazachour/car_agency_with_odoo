# Car Agency Management - Odoo Module

A custom Odoo module developed to manage the operations of a car rental/sales agency, built during my internship at **Softifi** (July - August 2024).

## Overview

This module extends the Odoo ERP platform to handle the core business operations of an automotive agency, including vehicle inventory, brand management, and the main workflows involved in running the agency.

## Features

- **Vehicle Management** — Track and manage the agency's vehicle fleet with detailed records
- **Brand Management** — Organize and maintain a catalog of automobile brands
- **Agency Operations** — Handle the main business processes of the car agency
- **Structured Data Model** — Clear and normalized data organization following Odoo best practices

## Tech Stack

- **Odoo** (ORM Framework)
- **Python** — Business logic and module development
- **XML** — Views, menus, and data definitions
- **PostgreSQL** — Database
- **Git / GitHub** — Version control

## Installation

1. Clone this repository into your Odoo `addons` directory:
```bash
   git clone https://github.com/moatazachour/car_agency_with_odoo.git
```

2. Update the Odoo apps list:
   - Go to **Apps** → **Update Apps List**

3. Search for "Car Agency" and click **Install**.

## Project Context

Developed as part of my internship at **Softifi** in Zarzis, Tunisia. The goal was to build a functional, well-structured Odoo module that demonstrates an understanding of the Odoo framework, ORM, and the typical workflows of an automotive agency.
